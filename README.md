# SAFE CHEM website demo

A bilingual (Arabic-first) static website for SAFE CHEM — Part of AGRO SAFE.

## Preview locally
Open `index.html` in a browser. For best results, use a simple local server or GitHub Pages.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, e.g. `safe-chem`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a public `https://USERNAME.github.io/safe-chem/` URL.

## Before using for real customers
- Replace the CSS-made logo with the official SAFE CHEM logo asset.
- Replace the illustrative product-packaging mockups with approved original product photographs.
- Verify all product data against approved labels and technical documentation.
- Add official phone, WhatsApp, email, address and social links.
- Connect the enquiry form to a real email service or backend. The current form is a presentation demo and does not send or store enquiries.
- Confirm the 20+ years statement and its attribution to AGRO SAFE before public launch.

No paid API, database, or payment gateway is required for this static presentation demo.
